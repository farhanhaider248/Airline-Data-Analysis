✈️ Airline Data Analysis Project

📌 Project Overview

This project focuses on analyzing airline-related data to identify important trends, patterns, and business insights.

The complete analysis was performed using Python, SQL, and a Dashboard. The dataset was first cleaned and prepared using Python, followed by exploratory data analysis and SQL-based business questions. Finally, an interactive dashboard was created to visualize important insights and KPIs.

🎯 Project Objectives

- Clean and preprocess airline data using Python
- Handle missing values and duplicate records
- Perform Exploratory Data Analysis (EDA)
- Solve business-related questions using SQL
- Analyze airline performance and customer/travel trends
- Create meaningful KPIs and visualizations
- Build a dashboard for easy interpretation of insights
- Generate actionable business insights from the data
